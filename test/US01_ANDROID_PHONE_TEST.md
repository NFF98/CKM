# CAKAMI Sprint 1 / US-01｜Android 真人驗收腳本

> 這份清單是 **NOT_RUN** 的實機驗收操作，不是 CI PASS 宣告。
> 僅使用 PR #17 最新 commit 所打包的 ARM64 debug APK；請先核對 GitHub Actions 的 head SHA 和 artifact。

## 安裝注意

- 優先覆蓋安裝相同 App ID／簽章的 APK。**不要先解除安裝／清除 App 資料**：那會刪除 2.59 GB 的 Gemma 與私人 SQLite。若出現 Android 簽章衝突，先記錄畫面並回報，不要硬刪資料。
- 首次下載 Gemma 使用 Wi-Fi；下載並驗證完成之後，再啟用飛航模式驗證本地推論。手機開始下載時絕不應上傳個人圖片、文字或 OCR。
- 這次只測 Sprint 1 的本地意圖，不會搜尋真人、不會 Cloud 同步。Android 真機 E2E 未通過前，**US-01 不得標 PASS**。

## 一次測完整 US-01A～D

| 步驟 | 手機操作 | 應該看到 |
|---|---|---|
| 01 | 純文字 Drop：\`我想找人一起練 JLPT N2 口說\`，觸發本地 Gemma | 有證據的私人 Goal 候選（或模型誠實報錯），不只是一段詞義解釋；絕不自動確認 |
| 02 | 點「採用候選」→檢查／修改 Goal→親自按兩次確認 | SQLite 私人 Goal v1，重新開啟仍存在；沒有 Cloud Consent、沒有搜尋真人 |
| 03 | 在已確認 N2 Goal 的私人條件畫面，點「採用 Goal 裡的 N2 條件候選」 | 出現 \`OBSERVED\` 候選，**尚未**占用 slot |
| 04 | 點「由本人確認這個私人條件」，確認視窗二次按下 | \`CONFIRMED\`、B06 slot 1/8；重複輸入 \`N2\`／\`JLPT N2\`／\`日語二級\` 不應占第二個概念 |
| 05 | 點分享預覽，勾選「Goal」或已確認「JLPT N2」，明確確認本地逐項審核 | 本地版本事件＋已審核欄位；**仍顯示無 Cloud 上傳權限**。關閉重開仍可查；按撤回則失效 |
| 06 | 修改已確認 Goal（重新本人確認），再看本地分享審核 | 舊審核不再有效；不會把先前同意自動沿用到新版本 |
| 07 | 給 Goal 明確到期日期→取消 Intent，再看條件及預覽 | 撤銷後不可重新啟用；先前 slot 失效，沒有可用的分享欄位 |
| 08 | 另存純文字 \`パクる\` 並選只收藏 | 不應被強制猜成日文 N2 找學伴；不建立 Goal、配對或 Cloud 發布 |
| 09 | 分別存入 Fashion／Car 文字（沒有找人意圖）、無文字圖片 | 不擅自產生 Study Goal；無 OCR 文字時標 \`vision_unknown\`，不能裝作看懂像素 |
| 10 | 丟入有 JLPT N2 字樣的圖片，執行本地 OCR，再修正辨識文字 | OCR 原文和更正分開，本地 Gemma 走同一條 Goal 候選流程；來源修正後不重用舊候選 |
| 11 | Gemma 如真的提出必要追問，回答並再次推理 | 每筆來源最多兩題補問，另有本人 Goal 確認；**不會固定逼問八題**；如果不用問，0 題可接受 |
| 12 | 飛航模式，完全關閉／重啟 App，重做私人 Goal、期限、撤回、刪來源 | 本地仍正常。刪除來源後，私人 Goal／參數／本地審核歷史均應級聯消失；手機相簿原圖不能刪 |

## 手機回報格式

記錄每一步的 **PASS / FAIL / NOT_RUN**、手機 Android 版本、Gemma 狀態與問題畫面。第 01 步若模型不可用，不能把它算作「AI 推測 PASS」；記錄模型錯誤訊息。第 05 步的本地審核**不是**伺服器分享 Consent，Cloud 測試留給 US-02。
